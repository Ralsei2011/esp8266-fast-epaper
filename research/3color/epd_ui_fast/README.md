# epd_ui_fast — 横屏三色中文界面

`GxEPD2_290_C90c` + SSD1680 三色屏，横屏 296×128 逻辑画布，映射到物理 128×296。

## 页面

| 编号 | 页面 | 内容 | 刷新方式 |
|---|---|---|---|
| `P_CLOCK` | 时钟 | 左半红字（日期/周几/温湿度）+ 右半黑白（时间/电量/名言） | 左半 `0xD7` 全刷；右半 `GDR=144` 动态刷新 |
| `P_MENU` | 菜单 | 天气 / 时钟 / 设置 / 屏幕 / 阅读，选中项反白 | `0xD7` 三色 |
| `P_READ` | 阅读 | 12 页文本 | `0xD7` 三色 |
| `P_PANEL` | 清单 | 屏幕型号、驱动、参数 | `0xD7` 三色 |

菜单页 60 秒无操作自动回时钟页。

## 按键

板上只有两个可编程键（详见 `../ui-clock.md` 第 1 节）：中键 `GPIO0`（与屏 DC 共用）、
右键 `GPIO3`（UART RX）。

| 操作 | 键 | 时钟页 | 菜单页 | 阅读页 | 清单页 |
|---|---|---|---|---|---|
| 短按 | 中 | 打开菜单 | 上移 | 上一页 | 回菜单 |
| 短按 | 右 | — | 下移 | 下一页 | 回菜单 |
| 长按 0.6s | 右 | 进菜单 | 确认 | — | — |
| 长按 0.6s | 中 | 整屏重刷 | 返回 | 回菜单 | 回菜单 |

上电时按住右键 → 直接进菜单（V15 原厂逻辑）。

**GPIO3 是 UART RX，串口开着时内部上拉会被夺走**，所以 `readKeyR()` 每次读之前都要
重设一次 `INPUT_PULLUP`，否则右键恒读低电平、每 600ms 自动触发一次误确认。

**上电时不要按中键** —— GPIO0 是启动模式脚，按住会进烧录模式不开机。

## 刷新通道

```c
#define BOOT_SELFTEST   0     // 改成 1，上电跑白/格交替循环（验证刷新通道用）
```

`0xC8`（Mode 2，90ms）在本批 ① 号屏上**只跑波形、不出画**，四种上传/触发方式都试过，
全部失败。目前唯一能出画的通道是 `0xD7`（三色，100℃ 下 5.1 秒）。

完整实测数据和排查过程见 `../ui-clock.md` 第 4 节。**不要再用 90ms 这个数字做设计前提。**

## 关键常量

```c
#define W   296      // 横屏逻辑宽度
#define H   128      // 横屏逻辑高度
#define PW  128      // 物理宽 —— 寄存器级接口(PW/PH)必须用这个
#define PH  296      // 物理高
#define DYN_W 144    // 右半动态区宽度
#define DYN_X 152    // = W - DYN_W
```

`expSetRamArea()` / `expWriteRam()` 用的是**物理坐标**。传 `W`/`H` 会把 X 地址写到 36
（物理上限 15），数据全部丢失且不报错。这是本项目最难查的一个 bug。

## 编译

```bash
python tools/build.py epd_ui_fast            # 只编译
python tools/build.py epd_ui_fast --flash    # 编译 + 烧录（COM62，460800）
```

依赖：`epd_panel.h`（屏幕适配表 + 快刷注入开关）、`epd_time.h`（时间基准）。

## 串口命令

固件启动 180 秒内可通过串口发送单字符：

| 字符 | 作用 |
|---|---|
| `t` | 跑一遍自检循环 |
| `m` | 进菜单 |
| `c` | 回时钟 |
| `p` | 屏幕清单 |

注意：按键轮询每 5ms 切一次 GPIO3 方向会打断 UART 接收，所以串口命令**不是随时可靠**的，
这也是自检改成上电自动跑的原因。
